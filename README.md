# Truk Afrik website

Website source and verified deployed files for https://www.trukafrik.com/.

This repository excludes mailbox data, passwords, `.env` files, private enquiry settings, databases, local backups and development dependencies. The working server enquiry configuration must remain outside `public_html` and must never be committed.

The current deployed homepage uses the approved 28-second metallic-logo truck video, with responsive specification overlays synchronised to its four truck segments. The Events recap remains on `/events`.

Source and deployment manifests will be added after verification. A fresh source build must not be deployed over the live site without reconciling the recorded deployment patches.
